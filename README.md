# Unit converter
\
This program **converts** a temperature from *Celsius* to Fahrenheit.

## Installation
The course page in on the [TUM](https://tum.de/) website

### Requirements

- Python 3
- pytest `lasdhvk`
- A terminal


## Usage

1. Run python3
2. convert.py
3. Type a temperature

## Example
```cpp
print("0 C = 32 F")
```
